What happens to my link?

Your link and chosen language are sent to the extractor server, which requests captions from YouTube. The app holds a bounded cache in server memory and reuses results for up to ten minutes. Entries remain in memory until replaced or the server restarts. It does not write transcripts to a database or disk. The hosting providers may keep request logs. See GitHub Pages data collection and Render's privacy policy.
